# GhostRoom

로그인·설치 없이 같은 웹 주소를 열고, 같은 방 코드를 아는 두 사람이 이어져 글(특히 터미널 명령)을 주고받는 임시 대화방. 단일 `index.html`.

## 쓰는 법
1. **방 만들기**: 원하는 비밀번호를 치고 [방 만들기]. 뒤에 무작위 숫자 5자리가 자동으로 붙어 **방 코드**가 된다. 또는 [랜덤방 만들기] — 앞부분이 1~3자(영문 대소문자·숫자)로 무작위.
2. 방 안 위쪽의 **"비밀번호" 상자**를 누르면 방 코드가 보이고(옆에 [복사]), 다시 누르면 가려진다. 가려진 동안에는 화면 글자(DOM)에도 코드가 없다.
3. 방 코드를 상대에게 따로 알려 준다. 상대는 첫 화면 [받은 방 코드] 칸에 그대로 치고 [들어가기].
4. 각 글의 [복사], [전체 복사]로 복사한다. "코드처럼 보기"(기본 켜짐)는 고정폭으로 보여 준다. 보내기는 Ctrl+Enter.
5. 한 명이 나가면 남은 쪽에 10:00 카운트다운이 돈다. 10분 안에 돌아오면 멈추고, 아니면 남은 쪽의 화면·메모리(키, 기록, 방 코드)를 모두 지우고 첫 화면으로 돌아간다. 둘 다 나가면 남는 것이 없다.

## 보안 모델 (솔직하게)
지키는 것
- 글은 브라우저에서 AES-256-GCM 으로 암호화돼 오간다. 키는 방 코드에서 PBKDF2-SHA256(600,000회) → HKDF-SHA256 으로 만들고, 같은 마스터에서 중계 주제(topic)와 암호 키를 따로 갈라 낸다. 방 코드(비밀번호)가 중계에 그대로 나가지 않는다.
- 서버 저장 없음. localStorage·sessionStorage·IndexedDB·쿠키를 쓰지 않고 메모리에만 둔다.
- 셋째 사람 차단(입장 시각·무작위 id 로 앞선 둘만 유지), 재전송·중복 거부(msgId, 2분 넘은 것 버림), 메시지는 textContent 로만 표시(XSS 방지), 엄격한 CSP.

지키지 못하는 것
- 이 페이지는 **공개 MQTT 중계**(기본 `broker.emqx.io`, 실패 시 `broker.hivemq.com`)를 거친다. 중계는 암호문, topic, 접속 시각·크기·IP 는 볼 수 있다. 누가 언제 접속했는지는 숨기지 못한다.
- **방 코드가 짧으면 추측당할 수 있다.** 엿듣는 사람이 topic 을 보고 오프라인으로 코드를 대입해 볼 수 있다. PBKDF2 600,000회가 비용을 높일 뿐이다. **랜덤방 코드는 짧아서(최소 6자) 약하다. 중요한 내용은 긴 비밀번호로 방을 만들어라.**
- 상대 화면에 복사해 둔 글, 브라우저 확장, 키로거, 누가 어깨 너머로 보는 것은 막지 못한다. 화면에 보이는 글은 복사·스크린샷이 가능하다.
- 두 사람이 서로 다른 중계에 붙으면 못 만난다. 둘 다 EMQX 를 8초 시도한 뒤 HiveMQ 로 넘어가는 같은 순서를 따르고, 상태줄에 쓰는 중계 이름을 작게 보여 준다. 한쪽만 EMQX 연결에 성공하고 다른 쪽이 실패하면 어긋날 수 있다(새로 고쳐 다시 입장).
- 두 PC 의 시계가 2분 넘게 어긋나면 서로의 글이 버려진다.
- 입장 시각으로 셋째를 가리므로, 셋째 쪽 시계가 심하게 앞서 있으면 순서가 바뀔 수 있다. 상대가 비정상 종료한 직후(10초 안)에 다시 들어오면 셋째 판정 유예(12초)가 걸려 입장이 잠깐 늦어질 수 있다.
- 숨겨진(백그라운드) 탭은 브라우저가 타이머를 늦춰 하트비트가 끊길 수 있다. 상대에게 "나갔다"로 보이다가 돌아오면 다시 이어진다.
- 라이브러리(MQTT.js 5.10.1)는 jsDelivr 에서 SRI(sha384)로 고정해 불러온다. CDN 이 막히면 열리지 않는다.

## 시험
```
python -X utf8 tests/e2e.py              # 실제 공개 중계를 쓰는 종합 시험 (약 1분)
python -X utf8 tests/fallback_mobile.py  # EMQX 를 막아 HiveMQ 로 넘어가는지, 360px 가로 넘침
python -X utf8 tests/stamp_csp.py --check  # CSP 의 인라인 스크립트·스타일 해시가 맞는지
```
`index.html` 의 인라인 `<script>` 나 `<style>` 을 고치면 `python tests/stamp_csp.py` 로 CSP 해시를 다시 넣는다. URL 에 `?leaveSeconds=N`(3~600)을 붙이면 10분 대신 N초(시험 전용, "시험 모드" 표시).
